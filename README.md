# silksong_bot

A bot for Hollow Knight: Silksong that aims to earn Steel Soul and Speedrunner in one run (Weaver Queen ending, in-game time ≤ 18000 s).

- Design: [docs/DESIGN.md](docs/DESIGN.md) (Chinese)
- Research notes and sources: [docs/research/](docs/research/)
- Pinned game build: [versions.lock](versions.lock)

Game copies, decompiled code and datasets live outside the repo under `C:\ssbot\`.
