## 纹章 A/B 的先验（你的经验，2026-09-30）

- Wanderer：攻速最快（0.30 / 0.25 / 0.10 s），怪死得快、弹刀多、丝多；操作差时最好用。代价：下劈是 Slash、竖直范围小、无背后覆盖。

- 弹反只走白名单（§3.5.6）：日志里观测到拼刀、失败不靠面具也能活、YELLOW 和 PAUSE_PENDING 中禁用。

## 规划器：超过视野的长招（W4，2026-10-01 你的问题）

固定 0.8 s 视野的问题：前跳 → 冲刺 → 砍这种组合超过 0.8 s，收益（命中）落在视野外，规划器看不到，就不会选它（视野效应）。安全不受影响（每帧重查，只承诺视野内安全且留有退路的动作），影响的是打得好不好。W4 的做法：
- **宏动作：** 长组合作为一个原语，rollout 按它的全长加安全尾巴推演（例如 1.5 s），威胁预测也延长到同样长度。远期的支撑会变宽，所以这类宏只在 Boss 未来走向确定时（锁定在一个已知时长的长招或硬直里）才能通过安全检查，这正是人会用它的时机。
- **自适应视野：** Boss 进入时长已知的长招（例如 Bell Beast 的冲撞前摇约 0.6 s + 冲撞约 0.88 s）时，把视野延到招式结束加反应时间。
- **终点价值：** 推演终点按"是否处在惩罚位置、能否接上命中"打分，让铺垫动作也有分，在 savestate 批次上调参。
- **剧本里的已知惩罚：** "某招之后做某组合"直接写进 L3 剧本，规划器只负责验证安全。你的经验可以直接写成这种条目。
- **无敌帧：** rollout 记录下劈、弹反、受击后的无敌窗口，穿过攻击判定时不算命中；危险物和无视无敌帧的伤害照算。

## 行为表的条件变量（你的经验，2026-10-01）

- Bell Beast 的出招和距离无关；有的 Boss 和距离相关。
- 所以行为表不预设"按距离分档"：对每个决策状态，检验选择是否依赖距离档、你在 Boss 的哪一侧、你在竞技场里的位置、出招历史（上一招、连出次数、距上次某招的轮数）。只保留显著的条件（似然比检验或置换检验，做多重比较校正），不显著就合并，样本集中在少数格子里。
- 只影响概率（效率），不影响支撑（安全）：可能范围始终取全部观测和状态机结构上可能的分支。
- 你说出招和距离相关的：Lace 1 / Lace 2（S07、S26）、Last Judge（"链球看门"，S17）、Hunter's March 竖井顶部的蚂蚁二人组竞技场（S10）、"鸟房子车轮战"（我理解为 S11 Greymoor 钟的伏击屋，待你确认）。这些单元的行为表先查距离条件，检验结果和你的说法对不上时人工复核。
- Bell Beast 用作检验：距离应当被判为无关；试跑 2 场里冲撞 / 跳砸时你的 x 中位数 82.7 / 89.8，按你的说法应是小样本噪声，用约 290 场数据复核。
