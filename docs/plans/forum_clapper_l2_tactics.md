# Forum Clapper 双怪 L2 战术现状

更新：2026-11-06。源码基线：`0b1481774f04838a610e5d31a70acbfcdef623df`。范围为当前 w13 双 Clapper 的 B 臂开发路径。

**L2 已实现候选竞争，但战术意图、动作链和实机验收不是同一种完成状态。** 当前明确未实现的是：成团时“瞄准阶段贴砍，起跳后后撤，落地再回来砍”的完整第二分支，以及在它与后撤引导之间按空间选择的逻辑。返回中间已有代码和有条件的执行正例，持续空中下劈和双怪墙角突围仍未完成验收。

详细进度和实验规格以[主计划](forum_clapper_plan.md)为准。本页维护当前战术清单；后续修改原位更新对应条目，不把历史交付记录当作当前状态。

## 实现状态的含义

| 标记 | 含义 |
|---|---|
| 已实现 | 当前运行源码中有对应的 L2 决策逻辑；动作能否执行仍由动作层决定。 |
| 部分实现 | 已有意图或部分动作，但用户要求的完整行为、适用域或接续还不齐。 |
| 未实现 | 没有对应完整分支，不能靠现有动作偶然做出几步就算实现。 |
| 默认关闭 | 代码存在，但必须在明确配置中启用；不能当作最近实机已在使用。 |
| 有条件正例 | 在明确合成场景或录像条件下经过生产接口；不等于自然实机成功。 |

“实机已观察到”只覆盖实际发生的那次事件，不表示整条战术在所有局面通过。

## 战术实现一览

| 场景和期望打法 | L2 实现 | 当前行为 | 执行与验证状态 |
|---|---|---|---|
| 没有更高优先候选时，继续打当前怪 | 已实现 | `keep` 保持焦点和接近攻击偏好。 | 是现有基线；不保证怪永远不跳。 |
| 非焦点怪走到近处并开始近程招，换过去打它 | 已实现 | `near` 在新近程前摇、距离满足条件时参与竞争。 | 动作仍须满足对应踩头或平砍入口；不是看到前摇就强制换。 |
| 非焦点怪从背后跳来，钻过后接着打它 | 已实现 | `intercept` 选来怪，`hold` 保持同一次跳跃目标，避免马上切回。 | L2 已接；具体钻行和落点仍交动作与危险检查。 |
| 当前怪起跳后，改打另一只 | 已实现 | `takeoff` 等实际 `Jump/Air`，且英雄处在两怪之间时才提出换怪。 | 不适用于两怪都在英雄同一侧的成团局面。 |
| 进入两怪中间后，优先打离墙远的怪 | 已实现 | `middle` 在进入中间的事件上选目标；回中间的 `back` 也按外侧空间选目标。 | 不是每帧因微小墙距差反复换怪；还要与其他候选竞争。 |
| 已在两怪中间，一只前摇跳跃时，靠近它引导落点 | 已实现 | `middle_jump` 内的 `guide`：需要地面可输入、剩余瞄准时间够、引导后的中间有站位窗口。 | 是有条件意图；不保证动作层一定能及时到达。未知时保持，不硬引导。 |
| 已在两怪中间，一只起跳后，中间仍能站人，就贴站着怪平砍 | 已实现 | `middle_jump` 内的 `stand`，依据已锁落点、攻击覆盖和站位窗口决定。 | 已有地面站位/侧劈意图；完整路径仍须通过动作层。 |
| 已在两怪中间，一只起跳后，中间站不下，就比较钻跳怪和翻走路怪 | 部分实现 | `middle_jump` 内比较 `under/over` 的声明终点，选择离墙更远者；翻越输出踩头意图。 | L2 比较已实现；声明终点不是已验证动作终点。走路怪翻越及真实远侧交还仍未完成实机验收。 |
| 两怪成团、英雄在外侧：后撤拉远瞄准，起跳后钻回站着怪前平砍 | 已实现 | `cluster_route` 的 `bait → return`；后撤目标为起点外侧约 2.5 个怪宽，受墙边限制。 | 那一盘没有完成有效的距离标定；不能声称已测出足够后撤多少。 |
| 两怪成团、英雄在外侧：瞄准时贴着砍，起跳后后撤，落地再回来砍 | **未实现** | 没有独立、完整的这一分支。普通攻击/退避偶然做出部分动作不算。 | 未验收。当前后撤空间不足只截断后撤目标点，不自动切成这条打法。 |
| 在上述两种成团打法间，空间够选引导钻回，空间不足选贴砍后撤 | **未实现** | 尚未形成这个二选一选择器。 | 需要与实际回钻距离和站着怪的移动一起验证。 |
| 在外侧遇起跳威胁，有后撤空间就退开 | 已实现 | `retreat`：有特定墙距、身后空间和跳跃/余圈条件。 | 这是普通外侧撤离候选，不是“贴砍后撤再回来砍”的完整第二打法。 |
| 在外侧躲完近程招，尽快回两怪中间；有缝落地砍，无缝去中间上方 | 部分实现 | `back` 保持返回意图，按当前身体间隙选地面或空中；只有实际落进可站缝才完成。 | 地面有条件正例；空中首刀、失去出刀条件时交还、随后落缝有条件正例。新执行开关默认关闭，稳定连续下劈未验收。 |
| 外侧近程招时翻回内侧，或在狭窄中间踩头 | 部分实现 | `flip`、`overhead` 已提供对应站位和踩头意图。 | 不能将“有踩头意图”写成“完整翻越或连续踩头已通过”。 |
| 两怪把英雄憋到墙角时，用专门路线突围 | **未实现完整打法** | 现有普通动作可能寻找出路，没有已验收的专门双怪墙角突围方案。 | 当前优先做好返回中间；尚未证明能完全避免入角。 |

## 分数竞争与互斥

只有满足入口条件的候选才参与比较：

`实际得分 = 战术最高分 × 适用度 − 换目标成本`

换目标默认扣 5 分，同分时偏向保持当前目标。最高分可通过 `L2Rules.clapper_scores` 覆盖，换目标成本由 `clapper_switch_cost` 控制。当前只有 `near` 使用连续适用度：`0.8 + 0.2 × max(0, 1 − 距离 / 8.05)`；其余已提供候选的适用度为 1，不适用时不入池。分数是偏好，不是成功概率。

| 规则标识 | 最高分 | 意义 |
|---|---:|---|
| `keep` | 50 | 继续当前焦点 |
| `intercept` | 130 | 接背后来跳的怪 |
| `hold` | 140 | 保持同一次跳跃的拦截目标 |
| `near` | 110 | 非焦点怪进入近程前摇 |
| `takeoff` | 90 | 焦点实际起跳后换另一只 |
| `middle` | 70 | 进入中间时选离墙远者 |
| `retreat` | 150 | 外侧撤离 |
| `flip` | 80 | 外侧近程招向内翻的意图 |
| `overhead` | 65 | 狭窄中间踩头意图 |
| `middle_jump` | 95 | 中间跳跃事件的引导、站位或绕行选择 |
| `bait` | 145 | 成团时拉远瞄准 |
| `return` | 145 | 成团怪起跳后钻回砍站着怪 |
| `back` | 70 | 近程招结束后返回中间 |

当前竞争仍有明确互斥和内部选择：

- `middle_jump` 先在内部按瞄准/起跳阶段选择 `guide/stand/under/over/hold`，再作为一个候选进入外层竞争。这些内部路线并非各自同时报分。
- 成团 `cluster_route` 生效时，外层只留下 `keep` 和这条路线的 `bait/return`，排除不兼容候选。空间不足不会自动产生尚未实现的贴砍分支。
- `back` 需要此前的近程威胁已结束，且没有当前中间跳跃、成团路线或拦截保持占着场景。它不是无条件最高优先级。
- 候选重新比较发生在敌人状态/实例、区域等事件变化时，以及默认每 6 个 L2 调用的周期点。L2 同步执行，不是每帧无条件切目标。

调低最高分可以抑制已入池的战术；调整分数不能让缺入口或被互斥排除的战术出现。

## L2 与动作层的分工

L2 指定目标、站位意图，以及接近后偏向平砍还是踩头。换目标后，现有 `EntryAttack` 根据可站身体间隙和到达后的攻击窗口选择 `side/stomp`；特定战术也会明确指定。动作层负责按当前高度、距离、横向速度、资源、状态、输入前缀和危险决定能否完成。

| 执行能力 | 当前状态 | 不能据此宣称的能力 |
|---|---|---|
| 接近后平砍 | 有现成入口，有条件落地/侧劈发键正例。 | 任意换目标后都能立即命中；地面侧劈模型未提供真实命中计数。 |
| 接近后踩头 | 有 `EntryAttack(stomp)`、既有接近和下劈执行。 | 任意新目标状态、任意起点都能踩；动态身体见证和动作入口仍有限。 |
| 翻过走路怪 | L2 的 `over` 目标和动作入口已有部分接线。 | 声明远侧站位就等于完成越怪、真实弹起和远侧交还。 |
| 回中间的第二身体局部余量 | `SSBOT_FORUM_TWO_RETURN_BODY` 默认 0；仅有范围受限的候选实现。 | 攻击/符文/其他危险都放宽，或路径已证明安全。 |
| 已结束近程招后的空中返回入口 | `SSBOT_FORUM_TWO_RETURN_AIR` 默认 0；可复用现有 B2 转移接近/下劈。 | 稳定地在两怪之间连续下劈直到分开。 |
| 空中无刀可出时交还 | 已有明确失去支持时的恢复，保留已承诺出刀和源锤尾。 | 随便一个没有出刀候选的瞬间都该放弃，或交还即可免除失败责任。 |
| 高位钩脸接近 | `SSBOT_FORUM_CHAIN_FACE_HOOK` 默认 0，未进入最近那盘观察配置。 | 已实机验证高位钩脸完成这条返回路线。 |
| 连续弹起对刀表 | 有有限资产/入口，`SSBOT_FORUM_CHAIN_BOUNCE_TABLE` 当前关闭。 | 任意前摇、姿态或跨怪距离都已在线覆盖。 |

现有精确按键承诺、几何否决和实际发键检查继续生效。L2 得分获胜不代表已发动作立即被取消，也不等于规划器所选行就是最终发送键。
